# Макеты

Перенесены из дизайн-артефакта владельца «Дворами — сайт городских квестов»: https://claude.ai/artifact/QXTWKju2DXV5paNgS5oAo2
Текущая версия — от 21.11.2026, 18:05 (артефакт v1795273559-95e2). Предыдущая — в истории git.

| Файл | Что это |
|---|---|
| `Main.dc.html` | Главная — «Синий час». Unbounded (заголовки), Golos Text (текст), JetBrains Mono (служебное). Палитра: #0E1630, #17224A, #34437A, #45558F, светлый #F3F1EA, акцент #FFC53D, голубой #8FC2FF |
| `ZilartQuest.dc.html` | Страница квеста ЗИЛАРТ — «Авангард». Oswald + Onest. #111111, #FFFFFF, красные #E1251B / #C81E17 |
| `HeroDoska.dc.html` | Запасной стиль «Доска улик» для будущего квеста. Dela Gothic One, Golos Text, JetBrains Mono |
| `canvas.json` | Раскладка досок |

Файлы `.dc.html` — формат дизайн-холста Claude; смотреть удобнее в самом артефакте. Для Инженера это референс, а не код для прода.
В макетах остались заглушки: [ЦЕНА], [N] человек, названия будущих квестов, контакты, оферта.

Пожелания владельца: тёмные блоки без резкого контраста светлых и тёмных; смело, премиально, по трендам; не должно выглядеть сгенерированным ИИ.

## Сайт теперь в `site/` (21.11.2026)
Рабочая вёрстка — `site/` (главная, `moscow/zilart-sinyaya-ptica/`, общий `assets/style.css`); стенд — GitHub Pages (`.github/workflows/pages.yml`). Макеты `.dc.html` остаются историей и референсом, их больше не правим. Скриншоты стенда — `platform/design/screens/`, логотип — `platform/design/logo.md`.
