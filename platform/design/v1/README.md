# Макеты v1

Перенесены из дизайн-артефакта владельца «Дворами — сайт городских квестов» (21.11.2026): https://claude.ai/artifact/QXTWKju2DXV5paNgS5oAo2

| Файл | Что это |
|---|---|
| `Main.dc.html` | Главная — «Вечерний двор». Шрифт Geologica, тёмно-синяя палитра (#0A131C, #0F1B27, #1B2C40, #22405F) |
| `ZilartQuest.dc.html` | Страница квеста ЗИЛАРТ — тёмный «Авангард». Oswald + Onest, #1E1916, #FF5A4F, #E1251B, #EFE6D6 |
| `HeroDoska.dc.html` | Запасной стиль «Доска улик» для будущего квеста. Dela Gothic One, Golos Text, JetBrains Mono |
| `canvas.json` | Раскладка досок |

Файлы `.dc.html` — формат дизайн-холста Claude; смотреть удобнее в самом артефакте. Для Инженера это референс, а не код для прода.

Пожелания владельца к доработке: блоки тёмные, без резкого контраста светлых и тёмных; смело, премиально, по трендам; не должно выглядеть сгенерированным ИИ.
