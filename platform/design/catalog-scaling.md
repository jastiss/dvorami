# Каталог дел при 5–25 делах (22.11)

- Источник данных — карточки каталога `li.qcard[data-case]` на главной (номер, `data-name`, `data-hook`, необязательный `data-wire`, статус `data-status`). Новое дело = одна карточка; карусель в первом экране строится из них же (`site/assets/site.js`), по умолчанию Дело №1.
- Телефон (<700 px): каталог — горизонтальная лента со снапом (видно край следующей карточки + пометка «листайте вбок →»); «Предложите свой квест» — последней в ленте. Планшет/десктоп: сетка 2/3 колонки.
- Фильтр по статусу сохранён; при >6 подходящих делах видны первые 6 и кнопка «Показать все дела (N)». Когда появятся города/районы — добавить кнопки фильтра `data-filter` по `data-district`, логика та же.
- Везде формат «Дело №N · Название», одна кнопка «Подробнее о деле»; дела в разработке отличаются только плашкой статуса.
- При >6 делах легенду карты под каталогом стоит свернуть до списка «готово / в разработке» (сейчас 3 пункта — не нужно).
