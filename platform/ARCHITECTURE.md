# Архитектура «Дворами» — по-простому

> Этот файл — для команды. Объяснение для владельца без технического опыта (что есть сейчас, нужно ли переезжать, где лежат аудио и видео, что сделать лично ему) — **`docs/infrastructure.md`**.

**Принцип:** своих серверов нет. Сайт — набор готовых страниц; там, где нужна логика (оплата, коды, общий прогресс, бот), — маленькие «облачные функции», которые просыпаются на запрос и стоят денег только за время работы. Квест — это данные (файл `quests/<id>/quest.json`), а не код: новый квест не требует программирования.

## Из чего состоит

```
Игрок / покупатель (телефон)
   │
   ├── Сайт и плеер квеста ─────────── GitHub Pages (стенд), потом dvorami.ru
   │     site/*.html, site/play/…        статические файлы, офлайн-кэш в телефоне
   │
   ├── Оплата ──────────────────────── ЮKassa (страница оплаты, чек в «Мой налог»)
   │                                      │ уведомление «оплачено»
   ├── API (облачные функции) ◄───────────┘
   │     Yandex Cloud: API Gateway + Cloud Functions (Python)
   │     create-payment · payment-webhook · code-status · activate
   │     progress · find-code · quest (контент по коду) · bot-webhook
   │        │
   │        ├── База: YDB serverless (заказы, коды, телефоны, прогресс) — Россия
   │        └── Письма: Yandex Cloud Postbox (код, «найти мой код»)
   │
   ├── Telegram: игровой бот (отзывы, «Что-то не так?», вопросы) ── сейчас GitHub Actions
   │                                                               → вебхук в ту же функцию
   └── Аналитика: Яндекс Метрика (site/assets/analytics.js)

Команда: GitHub (код, квесты, обезличенные отзывы feedback/*.jsonl), GitHub Actions (сборка стенда).
```

## Почему так

| Требование | Решение |
|---|---|
| Без своих серверов и админа | Облачные функции: нечего обновлять и чинить по ночам |
| Доступно из России, данные россиян — в России (152-ФЗ) | Yandex Cloud, регион ru-central1. Firebase и Supabase не берём: зарубежные, персональные данные туда нельзя |
| Почти бесплатно на старте | Бесплатный объём Yandex Cloud (ниже) с запасом покрывает тысячи продаж в месяц |
| Плохая связь на улице | Плеер — статичные файлы + service worker: после первой загрузки работает без сети, прогресс досылается позже |
| Один код на компанию, несколько телефонов | Прогресс хранится по коду в YDB; телефоны сверяются при каждом шаге |
| Мультиязычность и новые города | Квест — файл; язык — отдельный файл перевода; движок общий |

## Сколько стоит

| Сервис | Бесплатно в месяц | Наш расход на 300 продаж/мес | Источник |
|---|---|---|---|
| GitHub Pages / Actions | бесплатно для публичного репозитория | 0 ₽ | `docs/feedback-bot.md` |
| Cloud Functions | 1 млн вызовов и 10 ГБ×час **[сверить]** | ~30 тыс. вызовов → 0 ₽ | [Yandex Cloud: free tier](https://yandex.cloud/ru/docs/billing/concepts/serverless-free-tier), [тарифы функций](https://yandex.cloud/docs/functions/pricing) |
| API Gateway | 100 тыс. запросов **[сверить]** | ~30 тыс. → 0 ₽ | там же |
| YDB serverless | 1 млн единиц запросов и 1 ГБ **[сверить]** | ≪ 1 ГБ → 0 ₽ | [тарифы YDB serverless](https://yandex.cloud/ru-kz/docs/ydb/pricing/serverless) |
| Postbox (письма) | платно поштучно, доли копейки за письмо **[сверить]** | ~600 писем → единицы ₽ | [тарифы Postbox](https://yandex.cloud/ru/docs/postbox/pricing) |
| ЮKassa | без абонплаты | комиссия ~3–4% с продажи | `docs/payments.md` |
| Яндекс Метрика | бесплатно | 0 ₽ | `docs/analytics.md` |

Итого инфраструктура — **0–100 ₽ в месяц**; основная статья — комиссия платёжного сервиса. Цифры бесплатного объёма — из документации Yandex Cloud по знаниям команды, перед подключением сверяем (страницы по ссылкам). Для бесплатного объёма Yandex Cloud требует платёжный аккаунт с картой — это решение владельца (APPROVALS).

## Где что лежит в репозитории

| Путь | Что |
|---|---|
| `quests/<id>/quest.json` | Квест: точки, тексты, загадки, подсказки (источник истины) |
| `site/` | Сайт и плеер (`site/play/player.js`, `site/play/<id>/`) |
| `site/assets/analytics.js` | Метрика, цели, согласие на cookie |
| `scripts/feedback_bot.py` | Игровой бот (отзывы, «Что-то не так?», вопросы); `scripts/feedback_digest.py` — недельная сводка |
| `scripts/quest_bot.py` | Прохождение квеста в Telegram (вспомогательный путь) |
| `functions/` | (этап 1) облачные функции оплаты, кодов и прогресса |
| `docs/purchase-flow.md` | Путь покупателя, коды, схема данных |
| `docs/payments.md` | Статус, платёжный сервис, законы |

## Безопасность — коротко

- Ключи (ЮKassa, боты, Yandex Cloud) — только в секретах GitHub / Yandex Lockbox, никогда в коде.
- Уведомление об оплате проверяем повторным запросом в ЮKassa (подделать «оплачено» нельзя).
- Коды в базе — хэшем; проверка кода ограничена по частоте.
- Содержимое квеста после запуска продаж отдаётся функцией только по действующему коду (сейчас `quest.json` на стенде открыт — для теста это нормально, для продаж нет).
- В публичный репозиторий не попадают почты, телефоны, Telegram-аккаунты.
