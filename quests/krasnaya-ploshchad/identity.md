# Дело №4 «Стёртые имена» — паспорт стиля

Для Арт-директора и всех, кто пишет о деле. Сценарий — `story/scenario-v2.md`. Карта разнообразия — `docs/craft/variety.md`.

| | |
|---|---|
| Жанр | Реконструкция по обмерам. Не детектив: игрок не ищет виновника, а перемеряет площадь |
| Откуда жанр | Казанский собор снесли в 1936 году и выстроили заново в 1990–1993 годах по обмерам Барановского, сделанным до сноса. Площадь вернули те, кто успел её измерить |
| Тон | Точный, деловой, чертёжный; редкие живые фразы. Без страшилок и без пафоса |
| Роль игрока | Обмерщик, который перемеряет за бригадой 1936 года |
| Рассказчик | Обмерная ведомость 1936 года и пометки чертёжницы Аси *(вымышл.)*. Подсказки — «приёмы обмерщика» |
| Главная механика | Обмер: счёт модулей (арки, колонны), ось, сверка натуры с эскизом |
| Структура | Ведомость: каждая точка — строка «Было · Обмер · Вернуть?» |
| Финал | Решение: игрок сам заполняет последнюю графу, две концовки |
| Фирменный артефакт | Обмерная ведомость на кальке с эскизами |
| Визуальный мотив | «Ночной обмер»: чертёж синькой, который на глазах наливается цветом. Слева объект нарисован белой линией, к правому краю он уже стоит в кирпиче и в свете прожекторов: «что измерено, то можно поставить снова». Оси штрих-пунктиром, размерные стрелки, пометки карандашом, штамп листа, кнопки по углам. Под первым экраном идёт кирпичная стена с зубцами, на ней цифры квеста. В заголовке слово «стёртых» набрано контуром со штриховкой |
| Палитра-подсказка | Яркая синька `#0B2C7D` (ночью темнее `#061A55`, к низу светлее `#1046B8`), белая линия `#F1F6FF`, кирпич стены `#D03E27` / `#B5321E` — кнопки и акценты, золото подсветки и карандаша `#FFC94A` — надзаголовки, размерные линии, пометки. Калька `#EEF4FB` с сеткой. Золото здесь — свет прожекторов и карандаш, а не купола: открыточных видов не делаем (обновлено 23.11 по указанию владельца «ярче, запоминающееся») |
| Шрифты | Tektur 700 — заголовки (рубленый, как надписи по трафарету на чертеже); Golos Text — текст; Neucha — пометки от руки |
| Движение | На первом экране чертёж прорисовывается линией, затем стена и собор наливаются цветом, появляется пометка «вернуть?». При `prefers-reduced-motion` всё показано сразу |
| Не делать | Не показывать на обложке и эскизах ответы точек: вершины ворот, верх обелиска, число арок и колонн |

**Крючок карточки:** С этой площади убирали реку, ворота, собор и памятник. Перемерьте за бригадой 1936 года и решите, что вернуть.

**Подзаголовок:** Квест-прогулка по Красной площади и Александровскому саду с обмерной ведомостью 1936 года.

**Что узнаете по дороге**
- Над чем на самом деле перекинут каменный мост к Кремлю.
- Почему огромный зал напротив Кремля стоит без единой внутренней опоры.
- Из чего сложен грот у кремлёвской стены.
- Как собор, которого не было больше полувека, вернули на его угол.
- Кто на площади стоит не там, где стоял сто с лишним лет.
