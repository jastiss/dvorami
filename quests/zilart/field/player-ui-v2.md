# Экран прохождения, версия 2: мини-шаги

25.11.2026. По замечаниям владельца после прохождения с телефона. Правки — `site/play/player.js`, `site/play/player.css`, проверки — `scripts/player_check.js`. `quest.json`, коды доступа и проверка ответов не менялись; каркас общий для всех дел.

## Что изменилось

| Было | Стало |
|---|---|
| Всё дописывалось лентой, новое уезжало за экран | **Один мини-шаг — один экран**: реплика (или две-три коротких), картинка, загадка, разбор ответа, «точка пройдена». Новый экран всегда открывается сверху, главная кнопка «Дальше» — всегда внизу над навигацией |
| Верный ответ и объяснение терялись под заданием | После ответа — отдельный экран разбора: штамп «Верно · …», реплики, «Легло на доску улик» |
| Поле ответа прилипало к низу и ездило с клавиатурой | Поле и «Ответить» — в одну строку сразу под вопросом, в потоке страницы. Пока поле в фокусе, навигация и прилипшие кнопки убраны; если клавиатура закрыла поле — одна прокрутка ровно до поля (`visualViewport`). Неверный ответ не перерисовывает экран: поле, фокус и клавиатура остаются |
| Вернуться к прочитанному было нельзя | Стрелка «назад» и **оглавление** (строка над экраном): пройденные точки и мини-шаги, любой открывается для просмотра (без полей ответа), «К текущему шагу» возвращает. Непройденного в оглавлении нет — только «Впереди ещё N точек» |
| Прогресс только по точкам | Две линии: по точкам (в шапке) и по мини-шагам текущей точки (в строке над экраном) |
| Кнопка «Озвучка скоро» у отдельных реплик | Плеер реплики на каждом экране с речью: кнопка, дорожка, плашка «Аудио скоро». Режим **«Слушаю и читаю / Читаю»** — на обложке и в меню; текст на экране есть всегда |
| Заглушка «Картинка готовится» | Места под иллюстрации: плакат точки (номер и фигуры темы) на экране «на месте», плитка-портрет у имени героя, оформленное место под картинку с описанием того, что на ней будет |
| Длинные тексты простынёй | Одна раскрывашка со стандартным треугольником (▸ / ▾): текст длиннее 320 знаков («Подробнее»), «Напомнить, что было сказано» у загадки, «Как дойти», задание для детей, блоки «Что здесь правда», разделы оглавления |
| Финал: тексты и ссылка на бота | Карточка **«Дело № 1 · РАСКРЫТО»** для снимка экрана (дата, время в пути, точки, подсказки — без разгадки), «Поделиться», пять звёзд, «Оставить отзыв в Telegram» (`done_zilart`), затем «Что здесь правда, а что мы придумали» |

Дорога теперь тоже по экранам: как дойти → разговор в пути → вопрос на ходу (по желанию) → экран «идём» с кнопкой «Мы на месте». Картинка или письмо, на которые нужно смотреть, отвечая, стоят на экране загадки над полем.

Переходы: экран въезжает со стороны движения, штампы ставятся — только `transform`/`opacity`; при `prefers-reduced-motion` анимаций нет (тест это проверяет).

## Как устроено (для тех, кто правит)

- Экраны точки строит `pointFrames()` из тех же данных дела; `S.f` — экран, на котором игрок (сохраняется, переживает перезагрузку), `S.hist` — ответы пройденных точек для просмотра. Старые сохранения открываются на начале текущего шага.
- Сколько текста на экран — три числа в начале блока «мини-шаги»: `BUDGET` (330 знаков на экран), `INLINE` (реплики до 100 знаков остаются на экране загадки), `FOLD` (320 — сворачивать под стрелку).
- Оценка: `localStorage` (`dvorami:rating:<дело>`), функция-заглушка `sendRating(value)` с TODO — серверного приёма нет.

## Что осталось для аудио

1. Записать реплики и положить файлы; в `quest.json` у реплики — `"audio": "media/audio/….mp3"` (или одна запись на блок: `audio` у точки, шага, `walk_audio`). Код менять не нужно: если у всех реплик экрана есть файл, плашка «Аудио скоро» сама сменяется рабочим плеером (подряд по репликам, прогресс, пауза); в режиме «Слушаю и читаю» запись запускается при переходе на экран.
2. Решить, как файлы попадают на стенд: сейчас `media/` рядом со страницей дела не собирается (`pages.yml`), а дело зашифровано — аудио будет лежать открыто.
3. Проверить автозапуск на iPhone (Safari может не дать начать запись без касания — тогда остаётся кнопка).
4. Портреты героев — поле `img` в `speakers`; картинка точки — `img` у точки; остальные картинки — как раньше, `img` в репликах.

## Проверки

`node scripts/player_check.js` — дело целиком, 3 ширины × 2 темы: новое сверху, главная кнопка и поле на виду, поле не сдвигается при «клавиатуре», возврат к мини-шагу и обратно, в оглавлении нет непройденного, стрелки у свёрнутых блоков, режим «Читаю», финальная карточка без слов-ответов, оценка сохраняется.
