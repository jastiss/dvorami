## Пройти квест в браузере

Плеер: https://jastiss.github.io/dvorami/play/zilart/ — полевой тест: https://jastiss.github.io/dvorami/play/zilart/?field=1 (в Telegram-боте команды — `/quest`).

- Открыть ссылку на телефоне → «Открыть дело» → по точкам. Следующая точка открывается только после текущей; «Открыть в Яндекс Картах» — путь к ней.
- Внизу: «Улики» (доска), «Заметка» (к текущей точке), «Повторить» (вернуться к текущему заданию), «Ещё» (режим «Солнце», «Закончить», «Начать заново», отчёт).
- Прогресс хранится в браузере телефона: страницу можно закрыть и открыть снова. После первой загрузки плеер работает и при слабой связи.
- `?field=1`: на каждой точке — «что проверить», записываются время (вышли / на месте / закончили), неверные ответы, подсказки, заметки. «Ещё» → «Отправить отчёт» → Telegram (или «Скопировать» / «Скачать .txt»).
- Данные — этот `quest.json`: при сборке Pages (`.github/workflows/pages.yml`) он копируется в `site/play/zilart/`. Для локальной проверки: `cp quests/zilart/quest.json site/play/zilart/ && cd site && python3 -m http.server` → http://localhost:8000/play/zilart/?field=1
