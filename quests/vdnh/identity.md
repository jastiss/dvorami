# Дело №7 «Шестнадцатая сестра» — паспорт стиля

Для Арт-директора и всех, кто пишет о деле. Сценарий — `story/scenario-v2.md`. Карта разнообразия — `docs/craft/variety.md`.

| | |
|---|---|

| Не делать | Не показывать на обложке вершину шпиля, надпись на арке, число блоков ракеты (ответы точек) |

**Крючок карточки:** Республик пятнадцать, а золотых сестёр у фонтана шестнадцать. Шестнадцатая просит вас прислать ей открытки с выставки.

**Подзаголовок:** Квест-прогулка по ВДНХ: альбом открыток для статуи, которая семьдесят лет не сходит с места.

**Что узнаете по дороге**
- Откуда у фонтана шестнадцатая сестра и чья она.
- Где «Рабочий и колхозница» стояли до ВДНХ и почему теперь стоят выше.
- Сколько имён сменила выставка.
- Что раньше гремело в павильоне, где теперь космос.
- Из чего собран цветок по уральской сказке.
