Владелец о нынешнем голосе (eleven-v4, Charlie): «нормальный, но хочется ближе к настоящему голубю и попробовать женский». Основа — `../research/pigeon-sounds.md`.

Текст — точно из `00-fal-test.md` (слова не меняются; добавлены только теги). 242 символа.

## Вариант А — «голубиный»
- `elevenlabs/tts/eleven-v4`, голос **Callum** (мужской, с хрипотцой), `stability: 0.3` (больше выразительности), `similarity_boost: 0.75`, `language_code: "ru"`, `output_format: "mp3_44100_128"`.
- Текст:
```
[throaty, cooing softly] Курлык. [playful] То есть здравствуйте! Сыщик Зиля, отдел пропавших чудес. В архиве завода нашли телеграмму: «Синяя птица дома. Встречайте». Ни подписи, ни даты. [conspiratorial] Поможете? Только поторопимся — птицу ищет ещё кое-кто. [grumbling] С усами.
```
- Сборка (ffmpeg): воркование SFX (~2 с) → 0,15 с тишины → реплика.

## Вариант Б — женский, тёплая сыщица
- `elevenlabs/tts/eleven-v4`, голос **Jessica** (женский, тёплый, игривый), `stability: 0.4`, `similarity_boost: 0.75`, остальное как в А.
- Текст:
```
[warm, playful] Курлык. То есть здравствуйте! Сыщик Зиля, отдел пропавших чудес. В архиве завода нашли телеграмму: «Синяя птица дома. Встречайте». Ни подписи, ни даты. [conspiratorial] Поможете? Только поторопимся — птицу ищет ещё кое-кто. С усами.
```
- Без подмешанного воркования («птичность» мягче — в интонации); по желанию — то же SFX тише на −8 дБ.

## После генерации
