# Бриф: платформа

Требования владельца. Меняет только владелец.

## Продукт
- Платформа самостоятельных городских квестов. Сначала Москва, потом другие города и места.
- Сначала на русском, потом версии для иностранных туристов. Иностранцы должны находить квесты через поиск (SEO).
- Продажа через Tripster; уникальный ключ выдаётся автоматически после покупки.
- Аудитории: взрослые, семьи с детьми, дети.
- В квестах — аудио, видео, текст, изображения (сгенерированные ИИ, уникальные).

## Сайт
- Модный, захватывающий, вызывает предвкушение приключения и тайны. Место, куда идут, когда не знают, чем заняться в выходные.
- Смелый, премиальный, в духе текущих трендов; не должен выглядеть сгенерированным ИИ.
- Главная — тёмная (концепция «Синий час», в макете v1 — «Вечерний двор»). **Без резкого контраста светлых и тёмных блоков: блоки тёмные.**
- У каждого квеста своя страница в своём стиле. ЗИЛАРТ — «Авангард» (тёмный). «Доска улик» — оставлен для другого квеста.
- Первая версия макетов: `platform/design/v1/`.

## Название и домен
- Название — **«Дворами»**, домен **dvorami.ru**. Запасной вариант — sledami.ru.
- Смысл: прогулка не по проторённым путям, интересные улочки, разгадывание тайн и загадок.
- Отвергнуты: «Шагадка» (некрасиво), «Гулики».
- Критерии названий (для будущих продуктов и линеек): благозвучное; простое написание латиницей без двусмысленных букв (например, y); чередование согласных и гласных; не больше трёх слогов; смысл понятен сразу; запоминается; легко гуглится без путаницы.
