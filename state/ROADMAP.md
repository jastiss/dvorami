# Дорожная карта — как команда работает без вводных

Ведёт Продюсер; пересматривает по понедельникам в недельном итоге и при каждой смене вехи. Цели и вехи — `state/GOALS.md` (меняет владелец); здесь — порядок, в котором мы к ним идём.
_Обновлено: 2026-11-26 (ответ на вопрос владельца 25.11 22:45–22:48 о helicopter view)._

## Видение
«Дворами» — место, куда идут, когда не знают, чем заняться в выходные. Мерило — оценка игрока (цель 5★), а не число квестов. Поэтому порядок такой: **один квест, доведённый до продажи и до 5★ на живых людях → конвейер, который повторяет это качество дешевле → много квестов, суббренды, города, языки.** Всё, что не приближает первую продажу ЗИЛАРТа или не удешевляет следующий квест, — во вторую очередь.

## Узкое место сейчас
Путь ЗИЛАРТа к первой продаже: сценарий 5.3 → комментарии владельца → `quest.json` 5.3 → полевой тест → медиа (герои, голоса, улики) → продажи (ЮKassa, A-17) → Tripster. Каждая итерация двигает этот путь хотя бы на шаг; ожидание владельца на одном шаге не останавливает соседние.

## Порядок работ без указаний (сверху — важнее)
1. **Блокеры пути ЗИЛАРТа**, которые можно снять без владельца: правки по комментариям, правило 2/3 загадок, источники фактов, сборка `quest.json`, проверки плеера.
2. **Медиа ЗИЛАРТа** по выбранному владельцем кастингу: лист персонажа, голоса всех реплик, улики-документы, 2–4 видео в ключевых местах (вступление, финал) — в пределах одобренного бюджета fal.
3. **Движок и продажи — общее для всех квестов:** формат 5 в боте (T-84), выдача кода после оплаты (T-34, ждёт A-17), запасной путь отзывов без Telegram (T-71), процесс выкладки и CI (T-73).
4. **Второй квест по стандарту ЗИЛАРТа** — сценарная комната (`team/std/writers-room.md`) для одного дела, а не наброски семи сразу. Кандидат — №2 «Чистые пруды» (центр, сильная тема, готов набросок); вопрос владельцу — A-63. Начинаем, когда ЗИЛАРТ ушёл на полевой тест, чтобы Fable не делился между двумя сценариями.
5. **sledami.ru** (A-54): концепция суббренда с первого дня на уроках «Дворами» — SEO/GEO-разметка и тексты по `docs/seo/`, правила `team/std/site-check.md` и `language.md`, единый движок и формат 5, без повторения ошибок, которые владелец уже правил (полосы на обложках, внутренняя кухня, корявые формулировки). Только концепция и макет до продажи ЗИЛАРТа.
6. **Витрина и продвижение dvorami.ru:** SEO/GEO-страницы районов, тексты карточек дел по актуальным сценариям (ЗИЛАРТ — после принятия 5.3), канал — по одобрению постов.
7. **Остальные дела №3–7** — поддерживаем в виде набросков, развиваем только после второго квеста.

## Правила, когда вводных нет
- Бэклог ранжирует Продюсер по этому списку и гипотезам (`HYPOTHESES.md`, оценка ≥ 5); владелец видит итог в отчёте, а не согласует каждую задачу.
- Каждая итерация: ≥ 1 задача пути ЗИЛАРТа, ≥ 3 из гипотез, остальное — по порядку выше; недобор бюджета при непустом списке — ошибка.
- Свои идеи — сразу в задачи, если обратимы и бесплатны; деньги, публикации, смена фазы и видимый дизайн, который владелец уже принял, — вопросом в APPROVALS с картинкой «до/после».
- Замечание владельца к одному месту проверяем во всех похожих местах (все квесты, сайт, канал, sledami) и закрепляем правилом.
