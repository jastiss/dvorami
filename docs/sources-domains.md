# Законные исходники изображений: какие домены разрешить

Подготовил Медиапродюсер, 23.11.2026. Для владельца: какие сайты стоит открыть для среды Claude (curl), чтобы команда брала фото Москвы общественного достояния / свободных лицензий напрямую. Поиск (WebSearch) давал только адреса страниц, сами условия сайтов прочитать не удалось — колонка «Лицензии» основана на общеизвестном и **перед первым коммерческим использованием проверяется на странице конкретного снимка**. Правило из `docs/fal-guide.md` остаётся: лицензия подтверждается по странице файла, иначе снимок не берём.

**Важное наблюдение 23.11:** `upload.wikimedia.org` отдаёт **429 (слишком много запросов, retry-after 600 с)** нашему прокси и даже серверам fal после 4–5 запросов подряд. Wikimedia требует от скриптов User-Agent с контактом (почта или URL) — без него лимит жёсткий. Решение: владелец даёт служебный контакт для User-Agent (например, адрес проекта) — тогда лимит мягче; качать по одному файлу с паузой ≥ 5 с.

## Итог для владельца
**Разрешить (по приоритету):** 1) `pastvu.com` + `img.pastvu.com`; 2) `www.loc.gov` + `tile.loc.gov`; 3) `api.openverse.org` + `live.staticflickr.com`; 4) `www.europeana.eu` + `api.europeana.eu`; 5) `archive.org` (по мере надобности).
**Не нужно:** russiainphoto.ru, mos.ru (Главархив), goskatalog.ru — там нет свободных лицензий; снимки оттуда — только по договору.
**Для Commons:** нужен User-Agent с контактом — иначе 429 после нескольких файлов.
