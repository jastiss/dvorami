# Колонка «Где у игрока» в `research/facts.md` (H-110)

Проверка: `python3 scripts/facts_check.py` (входит в `node scripts/site_check.js` и `--sync`). Колонку ведёт Историк; меняет текст игрока — обновляет колонку тот, кто меняет.

## Формат ячейки

Части через `;` (или ` · `). Каждая часть — одно из:

| Что | Как писать | Пример |
|---|---|---|
| место в сценарии | `т.N id/путь`: N — поле `n` точки, `id` — её `id`, дальше **полный путь** по `quest.json` через `/`, индексы с нуля, диапазон `0–2` | `т.6 tatlin/steps/3/ok/1` |
| несколько мест одной точки | через `, `; голый индекс после запятой — тот же список | `т.10 boulevard/walk/0, 8`; `т.8 farewell/walk/3, steps/0/lines/5` |
| ветка | `[флаг=значение]` после пути; флаг — из `flags` или `clock` дела | `т.4 museum/steps/2/ok/1 [st4=A]` |
| дело целиком | `intro`, `summary`, `финал «…»` | `финал «Правда: завод»` |
| витрина | `сайт: <раздел>` | `сайт: справка «Как добраться»` |
| нигде | ячейка начинается с `—` (пояснение — в скобках) | `— (Вари в 5.5 нет)` |

Пояснения — в `(…)`, цитаты — в `«…»`: путь они не продолжают, а цитаты служат ключевыми словами (ниже). Русское слово после пути (`и карточки`, `— не звучит`) — тоже пояснение.

## Что проверяется

- **Ошибка:** нет точки N; `id` не той точки; поля или индекса нет (мёртвый путь); флага нет в деле; факт ❌ звучит игроку; строка таблицы с другим числом ячеек, чем заголовок.
- **Предупреждение:**
  - сокращённый путь (`т.6 ok/3` вместо `т.6 tatlin/steps/3/ok/3`) — скрипт находит место сам и печатает полный путь; несколько подходящих мест — «неоднозначно». Поиск поля идёт вверх (шаг → точка → дело) и, если не нашлось, вниз по точке; ветка и ключевые слова сужают выбор;
  - ссылка ведёт на текст, где нет ни одного ключевого слова факта (имена с заглавной, аббревиатуры, слова от 6 букв, слова в «…» факта и ячейки, годы цифрой и словами) — возможно, не та реплика (так найдено 9.1: «т.9 walk/0» — Шагал там не назван);
  - факт не ✅ (⚠️, 🔶 вне скобок) **звучит игроку**: ссылка на живой путь при текущих флагах (ветки `if` по дороге и `[флаг=…]` совпадают; ветки «по часам» считаются живыми), или `финал`/`intro`/`summary`, или `сайт`. Часть с `✅` (`финал — только «…» (Б-36 ✅)`) — звучит подтверждённая форма, не в счёт; так же помечать «звучит исправленное — в этой форме ✅» прямо в той же части, до `;`.
- Статус берётся из колонки «Статус» без скобок: `✅ 📜 (было 🔶)` — ✅. `👀 владелец` и `👤` — подтверждено. Таблица без колонки «Статус» (легенды) не проверяется.
