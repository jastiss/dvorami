# Где живёт сайт и где будут лежать файлы — простыми словами

> Ответ на вопросы владельца (23.11): «надо ли переезжать на хостинг и куда», «что делать с Yandex Cloud», «где будут храниться аудио, видео и картинки — на GitHub?».
> **Короткий ответ: сейчас делать не нужно ничего.** Пока продажи не открыты, нас всё устраивает и всё бесплатно. Когда скажете «A-17 да» — понадобится один аккаунт (Yandex Cloud) и 10 минут вашего времени. Всё остальное — наша работа.
> Цены найдены поиском 23.11.2026 и помечены 🔶: страницы тарифов мы не открываем (правило проекта), поэтому перед оплатой цифру нужно посмотреть по ссылке. Порядок величин команда знает и за него отвечает.

## Пять слов, которые дальше встретятся

| Слово | Что это на самом деле |
|---|---|
| **Хостинг** | Чужой компьютер, который всегда включён и отдаёт ваш сайт посетителям. Свой включённый компьютер держать не нужно |
| **GitHub Pages** | Бесплатный хостинг для простых сайтов. Там сейчас живёт наш стенд |
| **Облачная функция** | Маленькая программа, которая просыпается только на запрос («пришла оплата — выдай код») и спит остальное время. Платите за секунды работы, а не за месяц аренды |
| **База данных** | Таблица, в которой записано «кто купил, какой код, докуда дошёл». Нужна, когда появятся покупатели |
| **Объектное хранилище** | Склад для больших файлов (аудио, видео, фото). Платите за гигабайты и за скачивания |

## 1. Что есть сейчас и почему этого хватает

| Что | Где живёт | Сколько стоит |
|---|---|---|
| Сайт и страницы квестов | GitHub Pages | 0 ₽ |
| Плеер квеста (прохождение) | GitHub Pages, работает и без связи | 0 ₽ |
| Тексты квестов, картинки, схемы | в репозитории GitHub вместе с сайтом | 0 ₽ |
| Бот отзывов | бесплатные запуски GitHub Actions | 0 ₽ |
| Статистика | Яндекс Метрика | 0 ₽ |

Пока нет продаж, никаких персональных данных мы не храним, а содержимое квеста открыто — значит, не нужны ни своя база, ни свои серверы. **Переезжать сейчас не нужно, и это не «временное терпение»: для сайта-витрины GitHub Pages — нормальное решение.**

Что у этого варианта плохого (и почему он не навсегда):

- **Содержимое квеста лежит открыто.** Сейчас это не страшно, после открытия продаж — нельзя: любой сможет пройти квест бесплатно.
- **Нельзя принимать оплату.** На GitHub Pages нет места для программы, которая примет уведомление «оплачено» и выдаст код.
- **Нельзя хранить почты покупателей.** Данные россиян по закону хранятся в базах на территории России (`docs/legal/checklist.md`, п. 1.5), а GitHub — зарубежный.
- **Зарубежный хостинг — риск.** Роскомнадзор ограничивал работу иностранных хостинг-провайдеров 🔶 ([dp.ru, 02.2025](https://www.dp.ru/a/2025/02/13/sajti-bezpropiski-riskujut)). Сайт может однажды стать недоступным в России не по нашей вине.
- **Если закрыть репозиторий** (ваш вопрос A-20), GitHub Pages на бесплатном тарифе выключается — сайт и плеер перестанут открываться.

## 2. Когда понадобится переезд

Переезд нужен не «когда-нибудь», а в один конкретный момент — **когда вы решите открывать продажи**. Тогда одновременно нужны: закрытое содержимое квестов, приём оплаты, база с заказами в России и, желательно, сам сайт на российском хостинге.

До этого момента — ничего не делаем.

## 3. Три варианта: что выбрать

### Вариант A (рекомендуем). Сайт остаётся на GitHub Pages, «умная часть» — в Yandex Cloud

Сайт и плеер по-прежнему бесплатно отдаёт GitHub. Оплата, коды, прогресс и база с почтами — в российском облаке Yandex Cloud, где всё считается по факту использования: нет покупателей — нет счёта.

- **Цена:** 0–100 ₽ в месяц при наших объёмах. У Yandex Cloud есть бесплатный объём (миллион вызовов функций и 1 ГБ базы в месяц 🔶) — мы в него укладываемся с большим запасом ([бесплатный объём](https://yandex.cloud/ru/docs/billing/concepts/serverless-free-tier), [тарифы хранилища](https://yandex.cloud/ru/docs/storage/pricing), [Yandex Cloud про 152-ФЗ](https://yandex.cloud/ru/solutions/152-fz)).
- **Плюсы:** минимум работы и денег, данные россиян — в России, ничего не нужно обновлять и чинить.
- **Минусы:** сайт по-прежнему на зарубежном хостинге (риск из раздела 1); нужен аккаунт Yandex Cloud с привязанной картой — бесплатный объём без карты не включается.
- **Когда:** сразу после «A-17 да».

### Вариант B. Переезжаем целиком в Yandex Cloud

Сайт тоже переносится в российское облако (файлы сайта лежат в объектном хранилище, раздаются через сеть доставки), домен dvorami.ru смотрит туда же.

- **Цена:** примерно 150–700 ₽ в месяц 🔶 — хранение около 1 ₽ за гигабайт в месяц плюс плата за скачивания; при нашей посещаемости это десятки-сотни рублей ([тарифы Object Storage](https://yandex.cloud/ru/docs/storage/pricing); сравнение российских хранилищ — [tproger, 2026](https://tproger.ru/articles/rossijskie-s3-hranilishha-v-2026-godu-sravnivaem-ceny-trafik-i-z)).
- **Плюсы:** всё в одном месте и в России, быстрее открывается у российских посетителей, репозиторий можно закрыть, не ломая сайт.
- **Минусы:** дороже нуля; выкладка сайта становится нашей заботой (сделаем автоматической).
- **Когда:** разумно совместить с подключением домена — то есть при открытии продаж или чуть позже, если решите закрыть репозиторий.

### Вариант C. Обычный арендованный сервер (Timeweb Cloud, Selectel, Рег.ру и т.п.)

Арендуется «целый компьютер» в России, на нём ставится всё сразу.

- **Цена:** от 300–600 ₽ в месяц 🔶 за самую маленькую машину ([Timeweb Cloud](https://timeweb.com/ru/services/vds/), [Selectel](https://selectel.ru/), сравнение — [tproger](https://tproger.ru/articles/oblachnye-servery-v-rossii-sravnivaem-provajderov-na-odinakovoj)).
- **Плюсы:** привычно, всё своё, цена предсказуемая.
- **Минусы:** платите, даже когда никто не заходит; сервер нужно обновлять и следить за безопасностью — это регулярная работа живого человека. Для нашей нагрузки это как купить грузовик, чтобы раз в неделю возить пакет молока.
- **Когда:** не рекомендуем. Имеет смысл, если позже понадобится что-то, что в облачные функции не укладывается.

**Итог: A сейчас, B — когда подключим домен или если решите закрыть репозиторий. C — не берём.**

## 4. Где будут лежать файлы квестов

Коротко: **картинки — да, на GitHub; аудио и видео — нет, в объектном хранилище.**

| Что | Где | Почему |
|---|---|---|
| Картинки, схемы, иллюстрации (до ~250 КБ каждая) | в репозитории вместе с сайтом | их немного, они нужны на каждой странице, так быстрее всего |
| Фотографии мест | там же, сжатые до 1200×900 | правила — `docs/photos.md` |
| **Аудио** (озвучка, звуки на точках) | объектное хранилище Yandex Cloud | файлы тяжёлые, репозиторий для них не предназначен; оттуда же они раздаются в плеер |
| **Видео** | Rutube или VK Видео, вставка на страницу; либо объектное хранилище, если нужен свой плеер без рекламы | видео весит десятки и сотни мегабайт; хранить и раздавать его самим — дороже всего |
| Тексты квестов, загадки, маршрут | репозиторий (сейчас), после продаж выдаются программой только по коду | это сердце продукта, его нужно закрыть |

**Ограничения GitHub, из-за которых всё не положишь туда** (🔶 — сверить по ссылке перед большой загрузкой):

- файл больше 50 МБ — предупреждение, больше 100 МБ — загрузить нельзя ([GitHub: большие файлы](https://docs.github.com/ru/enterprise-server@3.18/repositories/working-with-files/managing-large-files/about-large-files-on-github));
- репозиторий рекомендуется держать меньше 1 ГБ, жёсткая граница — 5 ГБ ([GitHub: ограничения репозитория](https://docs.github.com/ru/enterprise-cloud@latest/repositories/creating-and-managing-repositories/repository-limits));
- сайт на GitHub Pages — до 1 ГБ, около 100 ГБ трафика в месяц ([GitHub Pages: ограничения](https://docs.github.com/en/pages/getting-started-with-github-pages/github-pages-limits)).

Для сравнения: сейчас весь наш репозиторий — несколько десятков мегабайт. Одна озвученная точка квеста (3 минуты речи) — около 3 МБ; двенадцать точек на семь квестов — уже под 250 МБ. Поэтому аудио сразу кладём в хранилище, а не в репозиторий.

## 5. Нужна ли база данных

Да, но только с продажами. В ней три маленькие таблицы: заказы (почта, сумма, номер платежа), коды (какой код к какому заказу, до какого числа действует) и прогресс (докуда дошла компания). Подробно — `docs/purchase-flow.md`, раздел 4.

**До продаж без базы можно обойтись полностью:** прогресс квеста хранится в самом телефоне игрока, отзывы — в файлах репозитория без имён. Так и работает сейчас.

Когда база появится, это будет YDB в Yandex Cloud — она тоже «спит, пока никто не пришёл», и бесплатного объёма нам хватает (`platform/ARCHITECTURE.md`).

## 6. Что сделать вам

### Нужно сейчас

**Ничего.** Ни аккаунтов, ни карт, ни денег. Единственное, что стоит решить в ближайшее время, — вопрос A-20 (закрывать ли репозиторий): если закрывать, стенд перестанет открываться, поэтому закрывать его имеет смысл только вместе с переездом.

### Когда скажете «A-17 да» (открываем продажи)

Шаги по порядку, каждый — ваш личный аккаунт, поэтому их не может сделать команда.

1. **Завести аккаунт Yandex Cloud** — чтобы у нас появилось место в России для базы заказов и программы выдачи кодов.
   Ссылка: https://console.yandex.cloud → «Войти» вашим Яндекс ID → «Создать платёжный аккаунт» → привязать карту (с неё ничего не спишется, пока мы в бесплатном объёме; Яндекс может сделать проверочное списание около 11 ₽ и вернуть его 🔶).
   Прислать команде: ничего, кроме слова «готово» — доступ выдадите по нашей инструкции.
   Цена: 0 ₽ при наших объёмах. Время: 10 минут.
2. **Подключить ЮKassa** как самозанятый — чтобы принимать оплату и автоматически выбивать чеки.
   Ссылка: https://yookassa.ru/platezhi-dlya-samozanyatyh/ → «Подключить» → анкета (сайт dvorami.ru, товар «доступ к онлайн-квесту», автоматические чеки самозанятого).
   Прислать команде: «ЮKassa подключена»; ключи (`shopId` и секретный ключ) — **не в чат**, а в секреты GitHub по нашей инструкции.
   Цена: 0 ₽ за подключение, комиссия ~3–3,5% с продажи 🔶. Время: 20 минут + проверка сервисом.
3. **Подать уведомление в Роскомнадзор** — чтобы законно хранить почты покупателей.
   Ссылка: https://pd.rkn.gov.ru (или через Госуслуги). Текст ответов на поля формы мы подготовим заранее.
   Прислать команде: «уведомление подано».
   Цена: 0 ₽. Время: 20 минут.
4. **Подключить домен dvorami.ru** — чтобы сайт открывался по нормальному адресу.
   Инструкция уже написана: `docs/domain-connect.md` (записи у регистратора + одна настройка в GitHub).
   Прислать команде: «домен готов».
   Цена: 0 ₽ (домен уже куплен). Время: 15 минут + ожидание.
5. **Решить про переезд сайта (вариант B)** — после того как всё заработает. Отдельных действий не потребуется, кроме вашего «да»: перенос сделаем мы, адрес сайта для посетителей не изменится.
   Цена: 150–700 ₽ в месяц 🔶. Время: 0 минут с вашей стороны.

### Что из этого может подождать

Пункты 1–3 нужны только для продаж. Пункт 4 (домен) можно сделать когда угодно — он ничего не стоит и ни от чего не зависит, а сайт сразу станет выглядеть серьёзнее. Пункт 5 — самый последний, и к нему мы вернёмся с готовыми цифрами.
