# Смысловой бэкап: что сохранено, что может пропасть, как восстановить

> Ответ на вопрос владельца 27.11: «Что нужно сделать, чтобы не потерять контекст проекта (например, при переезде в другой аккаунт ИИ) и быстро его восстановить».
> **Коротко.** Вся память команды уже лежит в репозитории GitHub и не зависит от аккаунта ИИ: каждая итерация начинает с чистого листа и читает файлы. Пропасть может только то, что живёт в аккаунтах (расписание, подключения, секреты, боты, домены). От вас — раз в месяц 5 минут по чек-листу (раздел 3) и менеджер паролей. Восстановление в новом аккаунте Claude — около 15 минут (раздел 4).

## 1. Что уже сохранено само

**Репозиторий GitHub `jastiss/dvorami` — это и есть память команды.** У ИИ нет «головы», где что-то хранится между запусками: всё, что команда знает и решила, записано в файлы и после каждой задачи отправлено на GitHub.

| Что | Где в репозитории |
|---|---|
| Смысловая выжимка — что за проект и как устроен (читать первым) | `docs/CONTEXT.md` |
| Протокол работы, бюджет, запреты | `CLAUDE.md` |
| Роли, плейбуки, стандарты качества | `team/` |
| Цели, статус, план, задачи, гипотезы, журнал решений | `state/` |
| Ваши указания (всё, что вы писали боту) и решения по вопросам | `DIRECTIVES.md`, `APPROVALS.md` |
| Сценарии, факты с источниками, данные плеера, медиа | `quests/` |
| Сайт и плеер, архитектура, справка для вас | `site/`, `platform/`, `docs/` |
| Отчёты всех итераций | `reports/` |

**Где копии:**
- **GitHub** — основная и пока единственная постоянная копия, с полной историей изменений.
- Каждая итерация ИИ скачивает репозиторий на время работы — это **не** бэкап: копия стирается после запуска.
- **Ваша копия** — появится, когда начнёте раз в месяц скачивать ZIP (раздел 3). Нужна на случай, если пропадёт сам аккаунт GitHub.

## 3. Раз в месяц — 5 минут

1. **Копия репозитория.** github.com/jastiss/dvorami → зелёная кнопка **Code** → **Download ZIP** (≈50 МБ) → сохранить к себе в облако с датой в имени. Это все файлы на сегодня, без истории изменений — для восстановления этого достаточно.
2. **Пакет контекста одним файлом** (для любого ИИ). github.com/jastiss/dvorami → **Actions** → «Бэкап — пакет контекста» → **Run workflow**. Через минуту откройте запуск, внизу — архив `dvorami-context`: два файла `.md`, полный (≈430 КБ, около 100 тыс. токенов) и облегчённый (≈260 КБ, без бэклога, гипотез и плейбуков — для ИИ с небольшим окном). Сохранить рядом с ZIP.
3. **Google Drive.** Папка «Дворами — сценарии квестов» → правой кнопкой → **Скачать** (Drive сам упакует в ZIP).
4. **Менеджер паролей** — проверить, что записаны: входы в GitHub, Claude, Google, Telegram (номер телефона), reg.ru и **даты продления доменов**, Яндекс ID, fal, ElevenLabs; значения секретов из таблицы выше. Если какой-то секрет не записан — не страшно: токен бота перевыпускается в @BotFather за минуту, но потом его надо вписать в GitHub.
5. **Свежесть выжимки.** Откройте `docs/CONTEXT.md`: дата «Обновлено» не старше месяца. Старше — напишите боту «команде: обнови docs/CONTEXT.md».

## 4. Как восстановить за 15 минут в новом аккаунте Claude

**Если GitHub на месте, меняется только аккаунт ИИ:**
1. Войдите в claude.ai новым аккаунтом (нужен тариф с Claude Code — это трата, решение ваше).
2. **claude.ai/code** → подключите GitHub и дайте доступ к репозиторию `jastiss/dvorami` с правом записи.
3. **Настройки → Connectors** → Google Drive (тем же Google-аккаунтом). fal — по желанию, только для генераций в чате.
4. **claude.ai/code/routines → New task** — две задачи:
   - Name `Дворами — итерация команды 06:59` и `Дворами — итерация команды 16:59`;
   - Schedule — ежедневно 06:59 и 16:59 **по Москве**; модель **Opus**;
   - Prompt — текст ниже, одинаковый у обеих;
   - у утренней: Trigger → **+ → API** → Fire URL и токен → в секреты GitHub `CLAUDE_FIRE_URL`, `CLAUDE_FIRE_TOKEN` (без этого не работает только `/run`).
5. У утренней задачи нажмите **Run now**. Итерация сама прочитает `CLAUDE.md` и `docs/CONTEXT.md`, отчёт придёт в Telegram как обычно.
6. Пришлите боту лимиты нового аккаунта: «лимит 0%, fable 0%».
7. Если старый аккаунт ещё открыт — выключите там задачи, чтобы итерации не шли дважды.

**Если пропал и GitHub** (ещё 30–60 минут): новый аккаунт и репозиторий → загрузить файлы из последнего ZIP → Settings → Pages → Source: GitHub Actions → вписать секреты по таблице → в первом чате с Claude попросить «замени jastiss/dvorami на новый адрес во всех файлах» (он встречается в скриптах бота и выкладки, `site/assets/analytics.js` и ссылках документов). Адрес стенда сменится. История изменений до ZIP потеряется, сами файлы — нет.

**Если другой ИИ, не Claude:** загрузите в чат файл пакета контекста (п. 2 раздела 3) и задавайте вопросы. Это будет консультант, а не команда: расписание, агенты и автоматические итерации устроены на Claude Code.
