## Правила плана
- Каждую неделю: один факт, одна загадка + ответ, один тизер, одно «живое» (опрос, было/стало, итоги).
- Тизеры — по очереди дел, только по тексту страницы дела. Если у дела нет страницы — тизер не ставим.
- Новый пост готовить не позже чем за 2 дня до даты: файл в `docs/marketing/channel/posts/`, картинка, `--check`.
- Сдвиг плана (владелец не одобрил вовремя) — двигаем всю цепочку «загадка → ответ», а не только один пост.
- Новости (старт продаж, новое дело) встают вне плана и вытесняют ближайший факт.
