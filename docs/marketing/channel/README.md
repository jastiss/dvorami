# Канал @dvorami_quest — как устроено

Публикация постов в канал по одобрению. Правила — `../channel-rules.md`, план — `../content-plan.md`, голос — `../tone-of-voice.md`.

## Что где

```
docs/marketing/channel/
├── posts/NNN-слаг.md     посты: frontmatter + HTML-подпись
├── img/NNN-слаг.png      картинки 1080×1350 (рисуются кодом)
├── img/_wordmark.html    логотип: знак «Арка-Д» + «дворами» (меняется только здесь)
└── README.md             этот файл
scripts/make_channel_img.py   генератор картинок (Playwright → PNG)
scripts/channel_post.py       публикатор (Bot API, без внешних зависимостей)
.github/workflows/channel-post.yml  запуск раз в час
```

## Как это работает

1. Пост — файл `posts/NNN-слаг.md`:
   ```
   ---
   date: 2026-11-25
   time: "19:30"          # МСК
   status: draft          # draft → approved → published
   image: img/001-znakomstvo.png
   ---
   🕊 <b>Текст поста в Telegram-HTML</b> …
   ```
   Опрос вместо текста — поля `poll_question`, `poll_options` (через `|`), `poll_multiple`.
2. Картинки рисует `python3 scripts/make_channel_img.py` — из кода, в стиле бренда, без чужих фото.
3. Проверка: `python3 scripts/channel_post.py --check` — разметка, длина подписи (≤1024), наличие картинки, **спойлеры** (сверка с ответами из `quests/*/quest.json` и `scripts/site_spoilers.json`). Красный `--check` не выпускается.
4. **Одобрение.** Первые посты одобряет владелец (см. ниже). После «да» Продюсер ставит `status: approved`.
5. Публикация: `channel-post.yml` раз в час запускает `channel_post.py`. Скрипт берёт один `approved`-пост с наступившим временем МСК, шлёт в канал, ставит `status: published` + `message_id` и коммитит. Один пост за запуск.

`--dry-run` показывает, что было бы отправлено, без отправки. Сеть к Telegram в песочнице закрыта — `--check` и `--dry-run` работают офлайн, это нормально.

## Шаги владельца (один раз, ~5 минут)

Бота `@dvorami_bot` вы уже создали (A-21). Теперь:

1. **Создайте канал** (если ещё нет): Telegram → «Создать канал» → название «Дворами», публичная ссылка `t.me/dvorami_quest` (если занято — выберите свободную и пришлите её нам: `маркетинг: канал t.me/<ваш-адрес>`).
2. **Сделайте бота админом канала:** в канале → «Управление» → «Администраторы» → «Добавить» → найдите `@dvorami_bot` → дайте право «Публикация сообщений» (остальное можно выключить) → сохраните. Всё по кнопкам, токен никуда вводить не нужно.
3. Если адрес канала не `@dvorami_quest` — добавьте секрет репозитория `CHANNEL_CHAT_ID` со значением `@ваш_адрес` (GitHub → Settings → Secrets → Actions). Если `@dvorami_quest` — ничего делать не нужно.
4. **Одобрение постов.** Мы покажем первые посты ссылками в отчёте. Ответьте в боте команды одной строкой, например: `посты 001–005 да` (или по одному: `пост 002 да`, `пост 003 нет, уберите шутку`). После «да» посты уйдут по расписанию в указанные даты и время.

Пока бот не админ канала или нет одобренных постов — ничего не публикуется.

## Частые правки

- Поменять текст поста — отредактируйте `.md`, прогоните `--check`.
- Перерисовать картинку — поправьте `scripts/make_channel_img.py`, запустите `python3 scripts/make_channel_img.py NNN`, посмотрите PNG в полном размере и в 360 px.
- Заменить логотип — только `img/_wordmark.html` (сейчас там знак «Арка-Д» и слово Unbounded 800, как на сайте).
- Генератор сам проверяет, что шрифты бренда применились, и падает, если нет.
- Сдвинуть дату/время — поля `date`/`time` во frontmatter.
