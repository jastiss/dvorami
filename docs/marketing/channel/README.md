## Как это работает

1. Пост — файл `posts/NNN-слаг.md`:
   ```
   ---
   rubric: Ответ            # рубрика из ../content-plan.md — обязательно
   slot: Н1 сб              # место в сетке плана
   date: 2027-01-16         # ставится при одобрении; у draft может не быть
   time: "11:00"            # МСК
   status: draft            # draft → approved → published
   image: img/004-fakt-zis-154.png   # только когда файл уже лежит в img/
   visual: рисованная графика, готова — img/004-fakt-zis-154.png   # или «без картинки» — обязательно
   ---
   <b>Ответ на вопрос № 3: гибридный</b> …
   ```
   Опрос вместо текста — поля `poll_question`, `poll_options` (через `|`), `poll_multiple`.
2. `visual` говорит, что за картинка и откуда: «без картинки», «рисованная графика», «архивное фото — что искать, где, какая лицензия», «современное фото владельца — какой кадр», «иллюстрация (fal, после одобрения) — что на ней». Правила по каждому типу — `../channel-rules.md`, «Картинки».
3. Проверка: `python3 scripts/channel_post.py --check`. Ловит: разметку, длину (≤ 1024, если картинка есть или запланирована), отсутствие файла картинки, **спойлеры** (ответы из `quests/*/quest.json` и `scripts/site_spoilers.json`), отсутствие `rubric` и `visual`, **механические признаки машинного текста** (штампы, восклицательные знаки, эмодзи, больше трёх тире, больше одного вопросительного знака — список в `../tone-of-voice.md`). Красный `--check` не выпускается.
4. **Одобрение.** Посты одобряет владелец. После «да» Продюсер ставит `date` по сетке и `status: approved`. У `approved` без `date` проверка красная.
5. Публикация: `channel-post.yml` раз в час запускает `channel_post.py`. Скрипт берёт один `approved`-пост с наступившим временем МСК, шлёт в канал, ставит `status: published` + `message_id` и коммитит.

`--dry-run` показывает, что было бы отправлено, без отправки. Сеть к Telegram в песочнице закрыта — `--check` и `--dry-run` работают офлайн.

## Шаги владельца (один раз, ~5 минут)

Бота `@dvorami_bot` вы уже создали (A-21). Теперь:

1. **Создайте канал** (если ещё нет): Telegram → «Создать канал» → название «Дворами», публичная ссылка `t.me/dvorami_quest` (если занято — выберите свободную и пришлите её нам: `маркетинг: канал t.me/<ваш-адрес>`).
2. **Сделайте бота админом канала:** в канале → «Управление» → «Администраторы» → «Добавить» → найдите `@dvorami_bot` → дайте право «Публикация сообщений» (остальное можно выключить) → сохраните. Всё по кнопкам, токен никуда вводить не нужно.
3. Если адрес канала не `@dvorami_quest` — добавьте секрет репозитория `CHANNEL_CHAT_ID` со значением `@ваш_адрес` (GitHub → Settings → Secrets → Actions). Если `@dvorami_quest` — ничего делать не нужно.
4. **Одобрение постов.** Когда решите начинать, ответьте в боте команды одной строкой, например: `посты 001–006 да` (или по одному: `пост 002 да`, `пост 003 нет, уберите шутку`). После «да» Продюсер поставит даты по сетке плана, и посты уйдут по расписанию.

Пока бот не админ канала или нет одобренных постов — ничего не публикуется.

## Частые правки

- Поменять текст поста — отредактируйте `.md`, прогоните `--check`.
- Перерисовать картинку — поправьте `scripts/make_channel_img.py`, запустите `python3 scripts/make_channel_img.py NNN`, посмотрите PNG в полном размере и в 360 px.
- Заменить логотип — только `img/_wordmark.html` (сейчас там знак «Арка-Д» и слово Unbounded 800, как на сайте).
- Генератор сам проверяет, что шрифты бренда применились, и падает, если нет.
- Сдвинуть дату/время — поля `date`/`time` во frontmatter.
- Новый вопрос — сначала карточка в `riddles-bank.md`, потом два поста: «Вопрос» и «Ответ».
