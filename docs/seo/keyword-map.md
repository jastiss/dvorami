# Карта запросов: какая страница что ловит

Дата: 2026-11-22. Автор: Маркетолог (SEO/GEO). Основа: `docs/seo/semantics.md` (кластеры 1–8) и `docs/seo/site-plan.md`.
Частотности по-прежнему нет: Wordstat недоступен. Для Чистых прудов, Коломенского и дел 4–7 (раздел 5–8, 27.11) кластеры собраны по составу страниц и известным достопримечательностям, без цифр (оценки «выше/ниже» — экспертные). Сверить с Wordstat тем же заходом, что в конце `semantics.md`.

УТП, которое несут все страницы (указание владельца 22.11): **в квесте узнаёшь о месте новое и незаезженное; исторические факты сверены с источниками, легенды названы легендами**. На витрине это видно в meta description, в seo-блоке (строка «Факты сверены по источникам» со ссылками) и в llms.txt.

Где на странице блок: seo-блок — секция между `<!-- seo:start -->` и `<!-- seo:end -->` прямо перед FAQ.

## Правило для будущих страниц квестов (шаблон)

Продублировано в `team/roles/marketer.md`, раздел «SEO каждой новой страницы».

1. **Запросы до текста.** Перед вёрсткой страницы — строка в этой карте: основной кластер + 8–15 локальных запросов (место, достопримечательности, история, персонажи, течения, «как добраться», «с детьми»), интент и блок, который их закрывает.
2. **title ≤ 60, description ≤ 160, оба уникальны.** title: «Квест по <району> без гида: <крючок или главное место> | Дворами». description: 2–3 главных места + УТП («малоизвестное, факты сверены с источниками») + старт у метро.
3. **H1 содержит место.** Название дела можно делать крупным, но «Квест-прогулка по <району>» должно быть внутри `<h1>`. H2 «Что вы увидите» — с названием района.
4. **Seo-блок перед FAQ** (`<!-- seo:start -->`…`<!-- seo:end -->`): справка о месте короткими пунктами — история, люди и течения, «что посмотреть рядом», «как добраться», внизу строка «Факты сверены по источникам» со ссылками. Каждый факт — только со статусом ✅ из `quests/<квест>/research/`; ⚠️ и 🌀 — только с оговоркой («говорят», «по одной версии»).
5. **Ни одного ответа загадки.** Перед вёрсткой сверить блок с таблицей точек сценария: не писать ответы, «почему» из загадок, годы-улики в связке с событием, разгадку ложных версий.
6. **Разметка совпадает с видимым:** Organization (ссылкой), TouristTrip (+ Product/Offer только когда есть цена и продажа), `about` — места и персонажи из текста, `itinerary` — только точки, открытые на странице, BreadcrumbList, FAQPage дословно по видимым вопросам. Проверка: `json.loads` + сравнение FAQ скриптом.
7. **Синхронно обновить** `site/llms.txt` (строка о квесте с фактами и статусом), `site/sitemap.xml` (lastmod), canonical и og:url на `https://dvorami.ru/<город>/<слаг>/`, своя OG-картинка 1200×630.

## Для Арт-директора (видимая часть, решение за вами)

- **H1 — сделано.** На всех семи делах «Квест-прогулка по <месту>» стоит внутри `<h1>` (`<span class="pre">`, шаблон `scripts/build_cases.py`; проверено 27.11).
- **H2 «Что вы увидите»** — по-прежнему без места на всех семи делах → «Что вы увидите в ЗИЛАРТе» / «…на Чистых прудах и Покровке» / «…в Коломенском» / «…на Красной площади» / «…в Китай-городе» / «…на Арбате» / «…на ВДНХ» (можно вторую часть мелким курсивом, как в «Вопросы *и ответы*»).
- **ЗИЛАРТ:** «Искусство вокруг» → «Искусство вокруг: улицы в честь авангардистов»; «Было / стало» → «ЗИЛ: было / стало».
- **Коломенское:** «Предание и то, что известно точно» → «Легенды Коломенского и то, что известно точно».
- **Главная:** «С кем пойти» → можно добавить подзаголовок «одному, вдвоём, с друзьями или с детьми» (запросы «с детьми», «для двоих»).
- **OG-картинки 1200×630 — сделано** (T-128): у каждого дела своя `assets/og/<дело>.png`, рисует `scripts/make_og.py`.
- Seo-блоки используют общий класс `.seo-ref` (стиль в `<head>` каждой страницы) и классы секций темы. Если хотите оформить их иначе — меняйте стиль, текст не трогайте без Маркетолога.
