- Хитровка, ВДНХ, Замоскворечье — общеизвестные места; перед разработкой Историк делает фактчек как для ЗИЛАРТа (`quests/zilart/research/facts.md`).

## Как выбирать следующий
Критерии (предложение): 1) самостоятельного квеста по району ещё нет; 2) старт у метро, кольцо 2–3 км; 3) есть что «читать» на месте (таблички, фасады, скульптуры); 4) поисковый спрос на район. Решение — за владельцем (через APPROVALS).
