# Формат дела: `quests/<id>/quest.json`

Плеер — `site/play/player.js`. Дело — данные: новый квест не требует программирования. Формат 3 (ЗИЛАРТ 3.1) работает как прежде; формат 5 добавляет поля, а не меняет старые, — любое поле можно не указывать.
Проверка: `node scripts/player_check.js` (дело из `quest.json`, зашифрованное, как на стенде) и `node scripts/player_check.js --data=scripts/fixtures/quest-format5.json --allow-missing-media` (все возможности формата 5 на трёх точках; с `--flags=t1:B` — ветка Б). Черновик дела — `--data=<файл>`.

## 1. Дело целиком

| Поле | Что | Формат |
|---|---|---|
| `id`, `title`, `version`, `lang`, `city`, `district`, `summary` | как раньше; `summary` — подзаголовок обложки | 3 |
| `intro` | экраны вступления: строка (текст, разметка Telegram `<b> <i> <code>`) или **список реплик** (раздел 3) | 3 / 5 |
| `points` | точки по порядку (раздел 2) | 3 |
| `finale` | экраны финала: строка или список реплик | 3 / 5 |
| `format` | `5` — пометка для людей; плеер смотрит на сами поля | 5 |
| `flags` | ветки А/Б: `{"st4": "A", "st10": "A"}` (раздел 6) | 5 |
| `speakers` | говорящие: `{"zilya": {"name": "Зиля", "style": "hero"}}` (раздел 3) | 5 |
| `letter` | письмо-улика, меняется по ходу (раздел 5) | 5 |
| `cards` | карточки, которые лежат на доске с начала дела | 5 |
| `finale_cards` | карточки, которые ложатся на доску в финале | 5 |
| `board_empty` | текст пустой доски | 5 |

## 2. Точка

| Поле | Что |
|---|---|
| `id`, `n`, `title`, `place`, `lat`, `lon`, `walk_m`, `check` | как раньше (`check` — список «что проверить» в режиме `?field=1`) |
| `walk` | экран дороги к точке: строка или **список реплик** |
| `walk_audio` | озвучка дороги (раздел 4) |
| `walk_ask` | **вопрос на ходу** или список: по желанию, на прогресс не влияет; поля как у шага (`text`, `lines`, `answers`, `all`, `replies`, `hints`, `ok`, `type: "choice"`, `cards`). После ответа или «Пропустить» показывается `ok` |
| `scene` | сцена на месте: строка или список реплик |
| `audio` | озвучка сцены |
| `steps` | шаги (раздел 3) |
| `clue` | улика формата 3 (буква, год, свидетель) |
| `cards`, `strike` | карточки на доску и вычёркивания — когда точка пройдена |
| `letter` | состояние письма после точки |
| `kids` | **задание для детей**: строка, `{text, answer}` или список; свёрнуто, на прогресс не влияет |
| `outro` | экран «точка пройдена»: строка или список реплик |

## 3. Шаг

Общие поля любого шага:

| Поле | Что |
|---|---|
| `type` | `info` / `say` (прочитать → «Дальше»), `ask` (ответ словами), `free` (любой ответ), `choice` (вариант), `pick` (карточки доски), `strike` (вычеркнуть лишнее), `board` (формат 3) |
| `lines` | реплики перед заданием (ниже) |
| `text` | строка задания; эмодзи в начале → тег шага, как в формате 3 |
| `tag`, `tag_style` | тег явно: `"tag": "По желанию"` (стиль `opt`), `think`, `look`, `turn`, `cat` |
| `title` | подпись свёрнутых реплик в пройденном шаге (иначе — имена говорящих) |
| `button` | надпись главной кнопки `info`/`say` (по умолчанию «Дальше») |
| `audio` | озвучка шага |
| `hints` | подсказки; три — «намёк → почти решение → ответ», последняя у загадки — ответ |
| `ok` | после ответа: строка или список реплик |
| `ok_on_skip` | показать `ok` и после «Пропустить» |
| `optional` | можно пропустить |
| `cards`, `add`, `strike`, `unstrike` | карточки на доску (определения или id) и вычёркивания — после шага (при любом исходе) |
| `letter` | состояние письма — **с началом шага** (реплика `{"doc": "letter"}` в этом шаге уже показывает новое) |
| `if` | ветка (раздел 6) |

### Реплика (`lines`, `scene`, `walk`, `intro`, `ok`, `outro`, `finale`)

| Вид | Пример |
|---|---|
| реплика | `{"who": "zilya", "text": "Курлык!"}`; `note` — пометка после имени, `audio` — кнопка «Слушать» под репликой |
| строка | `"Просто абзац"` |
| «стрелка» | `{"arrow": "hint", "text": "Застряли — здесь три подсказки"}`: цели `sound` (кнопка звука), `image` (картинка), `board` (доска улик: вкладка мигает), `hint` (подсказки), `plus` (вопрос на ходу), `letter` (письмо). Встаёт **под своим элементом** на том же экране; нет элемента — там, где написана. Показывается **один раз** за прохождение |
| картинка | `{"img": "media/ch1.jpg", "alt": "…", "caption": "…", "ratio": "3 / 2"}`; `"img": null` — **заглушка** «Картинка готовится» с подписью; файл не загрузился — та же заглушка, раскладка не прыгает |
| слои | `{"layers": ["a.jpg", "b.jpg", "c.jpg"], "alt": "…"}` — касание меняет слой |
| письмо | `{"doc": "letter"}` — текущее состояние письма; `{"doc": "letter", "state": "s6"}` — заданное |
| карточка | `{"doc": "card", "id": "c-photo"}` — карточка доски целиком |

Стили говорящих (`speakers.*.style`): `hero` (сплошная полоса цвета дела), `cat` (пунктир), `witness` (двойная), `radio` (точки, моноширинный), `titr` (курсив без имени — имя только для чтения с экрана), `note` / `card` (бумага), `letter` (бумага и рукописный курсив). Имя говорящего подписано всегда — различие не только цветом.

### Ответы

| Поле | Тип шага | Что |
|---|---|---|
| `answers` | `ask` | варианты, как в формате 3: слово или фраза совпадает с ответом целиком или словами подряд; `~` в начале — «содержит» (`~корзин`) |
| `all` | `ask` | ответ из частей: `[{"answers": [...], "missing": "Кому — верно. А какая вещь?"}, …]` — нужны все; совпала часть — `missing` той, что не совпала |
| `replies` | `ask`, `walk_ask` | «почти»: `[{"answers": ["~роща"], "text": "Тепло: это фамилия…"}]` — показывается вместо «не подходит». Порядок проверки: `answers` → `all` целиком → `replies` → `missing` |
| `placeholder` | `ask`, `free` | подсказка в поле |
| `options`, `answer`, `answer_flag` | `choice` | `[{"id": "А", "label": "…", "img": null, "reply": "…"}]`; `answer` — id верного; `answer_flag: "st7"` — верный вариант берётся из флага, если флаг равен id варианта (портрет «по натуре») |
| `pick`, `answers`, `near` | `pick` | выбрать `pick` (по умолчанию 2) карточек доски: `answers: [["c-pond", "c-seva"]]` (порядок не важен), `near: [{"set": [...], "text": "Тепло…"}]` |
| `items`, `img` | `strike` | `[{"id": "trees", "label": "Деревья", "keep": true, "reply": "Эти — ушли?"}]`: вычеркнуть все без `keep`, не тронуть с `keep`; `reply` — ответ на ошибку с этим пунктом |

## 4. Звук

`audio` у точки, шага, вопроса на ходу, реплики: путь к файлу (`"media/audio/ch1.mp3"`) — кнопка «Слушать / Пауза»; `true` — **место под озвучку**: кнопка «Озвучка скоро» (не играет, говорит, что звука пока нет). Нет файла по пути — тост «Озвучка ещё не готова», квест идёт дальше.

## 5. Доска улик и письмо

**Карточка** — `{"id": "c-pond", "title": "Пруд", "text": "…", "kind": "photo", "img": null, "alt": "…", "source": "…", "struck_label": "Вычеркнуто"}`. Определяется один раз — в `cards` любой точки, шага, вопроса на ходу или дела; в других местах на неё ссылаются по id. Источник («Остановка N») подставляется сам. `kind: "photo"` или `img` — кнопка «Открыть» (шторка с картинкой). Вычеркнутая — зачёркнута и со штампом «Вычеркнуто».
Доска формата 5 включается сама, если в деле есть `letter` или `cards`: сверху письмо, ниже карточки (новые первыми). На экране «точка пройдена» — карточки этой точки. В навигации — счётчик.

**Письмо** — `{"title": "Письмо", "note": "…", "start": "s1", "end": "s10", "states": [...]}`. Состояние:

| Поле | Что |
|---|---|
| `id` | имя состояния |
| `text` | строки письма; `▓` — пятно на месте слова (ширина постоянная — по пятну не понять длину слова) |
| `reveal` | слово под пятном проступило |
| `ruled` | на просвет: двойная линия по линейке под буквами |
| `tip` | кончик полоски: `stuck` — присох; `circles` — две линии до края и кружки, обведённые дважды |
| `stamp` | штамп поперёк («Не сдержано», «Доставлено») |
| `back` | оборот (виден, когда задан) |
| `caption`, `img`, `alt` | подпись; картинка над полоской, если появится нарисованная |

Состояние меняют `letter` у шага (с началом шага), у точки (когда пройдена), `start` и `end` у письма. Письмо открывается крупно с доски в любой момент.

## 6. Ветки А/Б

Любой элемент любого списка (точка, шаг, реплика, вариант, карточка, вопрос на ходу) может иметь `"if"`: `"st4=B"`, `"st4!=B"`, `"st4=A|A2"` или `{"st4": ["A", "A2"]}`. Элемент остаётся, если условие выполнено. Флаги — `flags` в деле; **по умолчанию `A`**. Обе ветки лежат в деле рядом; после выезда владелец меняет одну букву в `flags` — текст не переписывается.
Посмотреть ветку, не меняя дело: `…/play/zilart/?flags=st4:B,st10:B` (на телефоне, после кода). В проверке: `node scripts/player_check.js --flags=st4:B`.
Смена флага посреди прохождения меняет число шагов точки: прогресс текущей точки может съехать — флаги меняют до старта.

## 7. Состояние на телефоне

`localStorage` `dvorami:play:<id>`; к прежним полям добавлены `cards` (`[{id, n}]`), `struck`, `letter`, `arrows` (какие «стрелки» показаны), `wa` (вопросы на ходу текущей дороги), `reply`, `sel` (выбор в `pick`/`strike`). Старые сохранения открываются: недостающее заполняется.

## 8. Безопасность

На стенд дело попадает только зашифрованным (`docs/codes.md`). `scripts/codes.py leakcheck` ищет в сайте отрывки текстов дела — в формате 5 и в репликах, карточках, письме, вариантах, вопросах на ходу. Картинки и звук дела (`site/play/<id>/media/`) публичны: в именах файлов и подписях — без ответов (`team/std/spoilers.md`).
