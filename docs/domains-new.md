# Новые домены: дворами.рф, sledami.ru, следами.рф (25.11)

Владелец купил 25.11: **дворами.рф**, **sledami.ru**, **следами.рф** (dvorami.ru — с 21.11, подключение — `docs/domain-connect.md`, A-7).

Технические имена кириллических доменов (их просят некоторые панели и GitHub):
- дворами.рф = `xn--80adfstko.xn--p1ai`
- следами.рф = `xn--80ahcolj4a.xn--p1ai`

## Что к чему ведёт (рекомендация)

| Домен | Куда | Зачем |
|---|---|---|
| dvorami.ru | основной сайт (GitHub Pages, `docs/domain-connect.md`) | главный адрес |
| дворами.рф | переадресация 301 → https://dvorami.ru | кто наберёт по-русски, попадёт на сайт; в поиске один адрес, без дублей |
| sledami.ru | пока «припаркован» (без записей) → потом отдельный сайт линии 18+ | сайт делаем после одобрения концепции (A-54) |
| следами.рф | переадресация 301 → https://sledami.ru (когда тот заработает) | то же, что с дворами.рф |

Почему не «всё на один GitHub»: у одного репозитория GitHub Pages — только один свой домен. Второй домен на тот же сайт без переадресации дал бы дубль сайта для поисковиков.

## Шаг 1. дворами.рф → dvorami.ru (5 минут, у регистратора)

Сначала включите сам dvorami.ru по `docs/domain-connect.md` — переадресация на неработающий адрес бессмысленна.

1. В панели регистратора найдите у домена **дворами.рф** услугу «Переадресация» / «Web-forwarding» / «Перенаправление домена». У многих регистраторов она бесплатна при их DNS-серверах — проверьте цену на экране; **если платная — не подключайте, напишите нам** (есть бесплатный путь ниже).
2. Адрес назначения: `https://dvorami.ru`, тип — **постоянная, 301**, «с сохранением пути» (если есть такая галочка), без «маскировки»/фрейма.
3. Через 15–60 минут откройте `дворами.рф` — должен открыться dvorami.ru, а в адресной строке смениться адрес.

Бесплатный запасной путь (если переадресации у регистратора нет или она платная): отдельный маленький репозиторий на GitHub с одной страницей-переадресацией и своим доменом. Сделаем за итерацию, но репозиторий создаёте вы (или дайте доступ) — вопрос A-55.

## Шаг 2. sledami.ru и следами.рф — пока ничего

- Не ставьте записей и «заглушек» регистратора с рекламой (если регистратор поставил свою страницу-парковку с рекламой — отключите её в настройках домена).
- Включите автопродление и запрет переноса — как в `docs/domain.md`, раздел 4.
- Когда концепция линии 18+ будет одобрена, сайт sledami.ru поднимем отдельным репозиторием GitHub Pages; записи будут те же, что для dvorami.ru (4 записи A на `185.199.108–111.153` и CNAME `www`), только CNAME на этот новый репозиторий. Тогда же следами.рф — переадресацией на sledami.ru по шагу 1.
