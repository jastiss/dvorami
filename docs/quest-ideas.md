# Идеи квестов — копилка

Сюда записываем любые идеи будущих квестов и линий: владельца, команды, из разборов конкурентов. Одна идея — один пункт: что, почему интересно, что нужно проверить. Готовые к разработке дела — в `docs/next-quests.md`; правила жанра — `docs/craft/genre.md`.

Статусы: 💡 идея · 🔍 изучаем · ✅ взяли в работу · ⏸ отложили (почему).

## Механики (из разборов)
- Обвинение из трёх полей «кто / как / почему» и разбор неверной части — «Поймай убийцу» → H-32.
- «Скажите вслух, кто как думает» перед проверкой ответа → H-33.
- Показания свидетелей «для второго телефона» → H-34.
