# Как включить сайт на dvorami.ru — пошагово для владельца

> **28.11: не нужно.** Сайт переезжает в Yandex Cloud (A-72) — записи DNS теперь по `docs/yandex-cloud.md`, шаг 6. Если эти записи GitHub уже стоят в reg.ru, переносить их не надо.

Время: 10–15 минут вашей работы + до 24 часов ожидания (обычно 15–60 минут).
Что происходит простыми словами: сайт уже лежит на GitHub (стенд jastiss.github.io/dvorami). Домен dvorami.ru — это «вывеска». Нужно (1) у регистратора, где вы купили домен, записать, что вывеска указывает на GitHub, и (2) в GitHub сказать, что сайт теперь живёт на dvorami.ru.

Важно: пока действует решение A-6, сайт закрыт от поисковиков (noindex). После подключения он откроется по адресу dvorami.ru, но в Яндексе/Google не появится — это нормально.

## Шаг 1. Записи у регистратора (там, где покупали домен)

Найдите в личном кабинете раздел с DNS. Как он называется:
- **REG.RU**: «Домены» → dvorami.ru → «DNS-серверы и управление зоной» → убедитесь, что выбраны DNS-серверы REG.RU (ns1.reg.ru, ns2.reg.ru) → «Изменить» → «Добавить запись».
- **RU-CENTER (nic.ru)**: «Услуги» → «DNS-хостинг» → «Управление DNS-зонами» → dvorami.ru → «Добавить новую запись». После всех записей — кнопка «Выгрузить зону».
- **Beget**: «DNS» → dvorami.ru → «Редактировать».
- Другой регистратор — ищите «DNS», «Управление зоной», «Ресурсные записи».

Сначала **удалите** уже существующие записи типа A и AAAA для `@` и запись для `www` (регистратор часто ставит свою «заглушку»). Записи NS, MX, TXT не трогайте.

Добавьте записи (копируйте значения как есть):

| Тип | Имя (хост / субдомен) | Значение |
|---|---|---|
| A | `@` | `185.199.108.153` |
| A | `@` | `185.199.109.153` |
| A | `@` | `185.199.110.153` |
| A | `@` | `185.199.111.153` |
| CNAME | `www` | `jastiss.github.io.` |

- Если поле «Имя» не принимает `@`, оставьте его пустым (в некоторых панелях пустое = сам домен).
- Если CNAME не принимает точку в конце — уберите её: `jastiss.github.io`.
- TTL — оставьте по умолчанию (или 3600).
- Сохраните.

## Шаг 2. Настройка в GitHub (2 минуты)

1. Откройте https://github.com/jastiss/dvorami/settings/pages
2. В разделе **Custom domain** впишите: `dvorami.ru` → **Save**.
3. GitHub начнёт проверку DNS. Пока записи не «доехали», он пишет «DNS check unsuccessful» — это нормально, подождите и обновите страницу через 15–60 минут.
4. Когда появится «DNS check successful», поставьте галочку **Enforce HTTPS** (если она серая — подождите ещё, сертификат выпускается до суток).

## Шаг 3. Проверка

- Откройте https://dvorami.ru — должна открыться наша главная.
- https://www.dvorami.ru должен перекинуть на dvorami.ru.
- Старый адрес jastiss.github.io/dvorami сам перекинет на новый.
- Напишите в бот: «домен готов» — команда проверит все страницы и плеер.

## Если что-то не так

- «Сайт не открывается» через час — проверьте записи на https://dnschecker.org/#A/dvorami.ru (должны быть четыре адреса 185.199.10x.153).
- «Небезопасное подключение» — HTTPS ещё не выпустился, ждите до суток, затем включите Enforce HTTPS.
- Не получается — пришлите скриншот страницы DNS у регистратора в бот.

Источник адресов: официальная документация GitHub Pages «Managing a custom domain» (адреса 185.199.108–111.153 — постоянные адреса GitHub Pages).
