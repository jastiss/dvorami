# Общие стандарты команды

Каждый стандарт — отдельный файл: агент читает только те, что названы в его роли или задании. История правил — в `state/DECISIONS.md`.

- `team/std/language.md` — Язык текстов для игрока и покупателя
- `team/std/truth.md` — Правдивость и согласованность
- `team/std/spoilers.md` — Спойлеры
- `team/std/sources.md` — Источники и статусы фактов
- `team/std/riddles.md` — Загадки — числом
- `team/std/images.md` — Изображения и права
- `team/std/site-check.md` — Сайт — проверка перед сдачей
- `team/std/security.md` — Безопасность: секреты, публичный репозиторий, внешние сервисы
